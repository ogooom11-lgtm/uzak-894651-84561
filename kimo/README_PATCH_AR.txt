KIOM Mobile Patch v0.2

انسخ مجلد lib الموجود في هذه الحزمة فوق مجلد lib داخل مشروع تطبيق الموبايل.

التعديلات:
1) عند الضغط على تحقق من الاتصال تظهر حالة: جاري التحقق.
2) يبقى الجهاز في حالة جاري التحقق حتى يرد الكمبيوتر أو تنتهي مهلة 10 ثواني.
3) صفحة جديدة: رسائل العمليات، تعرض الاستلام والنجاح والفشل، مع زر حذف السجل من Firebase.
4) صفحة التطبيقات المفتوحة تعرض تفاصيل أوضح: اسم التطبيق، عنوان النافذة، عنوان صفحة المتصفح، الرابط، PID، الحالة، آخر تحديث.
5) دعم أكثر من 100 أيقونة لتطبيقات ومواقع مشهورة عبر AppIconRegistry.
6) دعم فصل صفحات المتصفح إذا أرسل تطبيق الكمبيوتر كل تبويب كمستند مستقل في open_apps/{deviceId}/items.
7) صفحة حماية المسارات فيها زر تعديل لكل قاعدة.
8) إصلاح تحميل صفحات طلبات الإذن ومنع التثبيت عبر إزالة استعلامات Firestore التي تحتاج Index مركب.
9) المحافظة على منطق عرض الأجهزة المحفوظة محلياً بعد الربط فقط.

بعد النسخ شغّل:
flutter clean
flutter pub get
flutter run

ملاحظة مهمة:
عرض كل صفحة متصفح كعنصر مستقل يحتاج أن يرسل تطبيق الكمبيوتر مستنداً مستقلاً لكل تبويب مع حقول مثل:
pageTitle, windowTitle, url, siteName, browserName
الموبايل الآن جاهز لاستقبالها وعرضها.
